# BigDawgVPN Releases

This public repository distributes official, production-signed Android APK releases of Big Dawg VPN.

- APK files are published as GitHub Release assets.
- `update.json` is the public in-app update manifest.
- Android source code remains in the private `AgameEnt/BigDawgVPN` repository.

Only releases built and signed by the official BDVPN workflow should be installed. Android will ask the device owner to approve installation.
